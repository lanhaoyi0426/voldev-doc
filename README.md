# voldev-doc

火山软件开发平台 用户手册 / 帮助文档（离线 HTML 版）。

## 简介

火山软件开发平台是一种目的硬件设备无关、目的软件环境无关、易学易用实用、完全本地化的软件快速开发平台。它采用独创的“语言之上的语言”（LOL）技术，屏蔽了程序对特定目标环境的依赖，使用同一种语法即可针对不同目标环境进行软件开发。
